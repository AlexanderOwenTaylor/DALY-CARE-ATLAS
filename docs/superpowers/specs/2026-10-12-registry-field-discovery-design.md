# Registry field discovery and readable summaries

Iteration19 follows the accepted exact-source-membership checkpoint. It repairs
DaMyDa, LYFO and CLL presentation inside the existing Clinical explorer. The
user has authorized iterative implementation with X1 researcher, Z3 clinician,
W0 legacy-comparison and Y2 developer teams. No additional approval is needed.

## Problem and outcome

The current registry category panels contain 48 DaMyDa, 39 LYFO and 38 CLL
withheld/null rows. LYFO and CLL turn many into empty chart rows. Large missing
denominator/date cards, repetitive caveats and empty curation blocks hide useful
current field profiles. Exact field actions are absent from many themes. V33's
compact thematic organization was useful; its old numbers are not current data.

A clinician must reach Stage and risk fields, Baseline markers, Treatment,
Response and follow-up, and Workup/genetics from each registry's opening view.
Each theme shows supported exact field evidence or one honest no-mapping state
with a useful source-field action. Source identity, availability, years/regions
and limits remain clear. These are field-discovery pages, not patient summaries.

## Scope and invariants

- Change the Clinical template and focused JavaScript tests only. Keep all

- Preserve HTTP and double-click offline use, global routes, molecular workup

  concept inference, unknown-source borrowing or expansion of private fields.

  aliases remain separate even when their profile availability differs.

## Safe category summaries

Partition original rows before label mapping, limiting or aggregation. A chart
requires a supported nonprotected category and a supplied finite nonnegative
count; zero is valid. Missing, suppressed, withheld, validation-blocked and
unknown restrictive statuses fail closed under the existing publication policy.
Retained flagged values must not enter labels, bars, titles, accessibility or
print. Do not sum distinct sources, fields, categories or scopes. Preserve
original metadata when adapting eligible rows for the existing chart renderer.

Mixed groups show safe rows and one withholding notice. All-withheld groups show
one notice and field evidence. Absent/unsupported summaries show one accurate
state and field discovery. No literal null categories or scale/coding footer
without a chart. CLL's generic and facet paths must not repeat the same exact
source/field/scope summary or add their counts.

## Exact task fields and interpretation

Use finite registry theme descriptors: stable ID, title, purpose, reviewed
source+field pairs, supported facet IDs and necessary inline caveats. Every card
joins its own current permitted columnRows profile using strict equality. The
dictionary supplies human names; keep raw source/field identity and an exact
Data tables field action. Empty panel_raw_field_rows does not hide profiles.
Unknown/missing pairs yield no asserted card and a source inventory fallback.

Required reviewed additions and corrections from X1:

- DaMyDa Response includes RKKP_DaMyDa/PB_MaksimaleRespons and SB_Respons; relapse
  flags remain separately named. Treatment includes the individually reviewed
  Reg_PlanlagtBeh_Daratumumab, PB_Behandling_Daratumumab and
  SB_Behandling_Daratumumab, preserving planned/primary/secondary context. These
  are finite examples, not a complete treatment algorithm.
- LYFO Response includes RKKP_LYFO/Beh_Responsevaluering,
  Rec_Responsevaluering and FU_Sygdomsstatus plus reviewed follow-up fields.
  Rec_Kemoterapiregime1 belongs in Treatment. Rec_DosisIGray and
  Rec_Operationstype may appear only as individually reviewed Treatment pairs.
  Unknown Rec_ fields do not automatically become Response evidence.
- Preserve CLL's finite Treatment/Response lists and form phase. Stadie means
  recorded myeloma stage, not ISS/R-ISS. LYFO's recorded stage is not a verified
  Ann Arbor encoding. Reg_CYTOGENRES means Cytogenetic result field, not
  interpreted risk. Separate FISH performed, probe and result roles using
  finite exact pairs. CLL Reg_Umuteret does not establish mutated/unmutated
  status from Yes/No without the codebook. LYFO disease-site fields are not
  workup or genetics; that unreviewed theme has a truthful source fallback.

Records with a value does not mean people, completed assay, exposure or response.
Configured panel units and source-profile units are separate, with absence and
validation limits retained per applicable field. Do not infer units from names,
restore withheld numeric summaries or reconstruct date bounds. Consolidate
general caveats but retain distinctions that change a field's interpretation.

## Layout, source scope and routes

Replace large KPI cards with a compact source strip, with separate labels for
source records, catalog fields and published profiles. Put unsupported patient
denominator/date span in one disclosure. Source-wide fields and years/regions
actions occur once per exact source. Keep duplicate/limited/unavailable states
from iteration18. Reviewed canonical field lists do not transfer to another
alias solely because it belongs to the same inventory family.

Dedicated registry summary rows are separate supplied evidence. Resolve an
unambiguous explicit exact source identity before attributing their metrics;
otherwise leave them unasserted with inspectable supplied scope. Legacy regex
summary selection must not replace the authoritative source inventory.

Use native theme anchors and compact visible sections, not another tabs/router
framework. Add registry-scoped theme to both existing route allowlists. Example:
#registries/reg-cll?theme=response. Validate per active registry, restore after
deferred rendering, focus/scroll through existing scrollToAtlasTarget, use one
delegated data-registry-theme handler and aria-current. Avoid global sub-tab,
sub-nav, data-tab and data-sub classes/attributes. Refresh, copied routes and
Back preserve theme; changing registry/top-level section drops stale theme.
Global search retains correct route scope. All sections remain printable.

Use plain purpose/action copy. Remove clinician-facing review, aggregate source
shape and generated KPI language from primary registry flows. New task/evidence
controls should have approximately 44px phone hit areas and wrap without overflow.

## Acceptance and limits

wrong/missing source pairs, aliases/duplicate/unavailable inventory and routes.

W0 checks regained thematic compactness against V33 without importing values.

checks HTTP/keyboard/history/print. Independent Y2 reviews final source.

This cycle does not validate registry value codebooks, release withheld counts,
expand source mappings, change R generation or split the Clinical payload. Those
require separate evidence and scoped work.
